# 用量小窗（USEAGE WINDOW） v0.1.1

Your agents have big plans. Your quota has office hours.

A small DeepSeek Harness Web plugin that keeps your usage numbers close and your tab count out of grad-school territory.

**Currently supports Claude subscriptions, Codex (ChatGPT) subscriptions, and DeepSeek API only.**

- Subscription usage windows and reset countdowns—not fictional subscription dollar balances.
- DeepSeek API ledger spend, call counts and cached official balance.
- Draggable window, four-corner docking, settings toggle and visibility-aware polling.
- Manual-refresh balance fix included.

Install the attached `.tgz` with `dsh plugin --profile web add ./dsh-usage-mini-0.1.1.tgz`, then restart the existing Web profile. Required upstream data plugins are not included; see README.

Two automated tests pass. This is not a fresh live-account certification across all providers or browsers. No automatic budget enforcement, model switching, or promised savings.
